# 数学模块 · 规划文档

数学学科（初中至高中阶段）分支体系的建设工作区。本文件是**总规划**：
说明任务背景、分支体系框架、交付形式与实施阶段。
具体的分支内容见 `syllabus.md`，后续设计与 english 模块一样收在 `FUTURE.md`。

---

## 1. 任务背景

**用户需求**：辅助完成数学学科分支的梳理与呈现，覆盖**初中到高中**学段
（义务教育七至九年级 + 高中阶段）。小学、大学等其他学段在其他窗口另行制作。

**设计原则**：每个人接受知识的方式不同，因此同一套分支体系用**四种形式**交付，
读者可按习惯各取所需：

| # | 形式 | 适配人群 | 产物 |
|---|------|---------|------|
| 1 | 结构化 Markdown 文档 | 阅读习惯：线性理解、逐层深入 | `syllabus.md` |
| 2 | 可视化图表 | 视觉习惯：先看全景再看细节 | 对话内联图表（可导出） |
| 3 | 交互式网页知识图谱 | 探索习惯：自己点开感兴趣的分支 | `math.html` + `math.css` + `math.js` |
| 4 | 教学演示文稿 | 讲授场景：课堂展示、汇报讲解 | `数学学科分支.pptx` |

**内容依据**：
- 初中：《义务教育数学课程标准（2022 年版）》——数与代数、图形与几何、统计与概率三大领域
- 高中：《普通高中数学课程标准（2017 年版 2020 年修订）》——必修与选择性必修课程，
  函数、几何与代数、统计与概率、数学建模活动与数学探究活动四大主题

## 2. 数学分支体系框架

```
数学（初中 → 高中）
│
├─ 初中（义务教育七至九年级）
│  ├─ 数与代数 ── 数与式 / 方程与不等式 / 函数
│  ├─ 图形与几何 ── 图形性质 / 图形变化 / 图形与坐标
│  └─ 统计与概率 ── 数据收集整理与描述 / 数据分析 / 概率初步
│
└─ 高中（必修 + 选择性必修）
   ├─ 函数（主线）── 函数概念与性质 / 指数函数对数函数 / 三角函数 / 数列 / 导数 / 函数应用
   ├─ 几何与代数 ── 平面向量 / 复数 / 立体几何 / 解析几何（直线与圆、圆锥曲线）
   ├─ 统计与概率 ── 统计 / 概率 / 随机变量及其分布 / 成对数据的统计分析
   ├─ 预备与工具 ── 集合与常用逻辑用语 / 等式与不等式 / 计数原理
   └─ 数学建模活动与数学探究活动
```

高中课程的结构性说明：必修课程（2 册）面向全体学生，覆盖预备知识、函数、
几何与代数、统计与概率；选择性必修课程（3 册）在必修基础上加深拓广，
供有进一步学习需求的学生选择。函数的教学贯穿高中全程，是高中数学的**主线**。

## 3. 目录结构规划

```
modules/math/
├── README.md      本文件（总规划）
├── syllabus.md    数学分支体系完整文档（交付形式 1）
├── math.html      学科页片段（交付形式 3，可仿 english 注入 #contentContainer）
├── math.css       网页样式（只作用于数学页内元素）
├── math.js        网页交互逻辑（ES module）
├── 数学学科分支/  PPT 项目目录（STORY.md、slides/、数学学科分支.pptx，交付形式 4）
└── FUTURE.md      后续考量（提过、这版刻意没做的设计，如小学/大学学段扩展）
```

> **已接入主站**：`index.html` 的数学导航项 `data-page="modules/math/math.html"`，
> `main.js` 在进入该页时动态 `import('./modules/math/math.js')` 并调用 `initMathApp()`；
> 切换学科时由 `main.js` 调用模块导出的 `unmount()` 清理状态。
> `pages/math.html` 保留为跳转页，兼容旧书签。三个文件仍可独立打开（片段自带启动脚本）。

## 5. 与其他模块的关系

- **english 模块**：已包含完整的单词复习引擎（Rust/WASM + FSRS 调度）。
  数学模块本期**不**做练习引擎，只做分支体系的知识呈现；若未来要做刷题/公式卡片，
  可参照 english 的引擎结构另立 `math/engine`，并在此记录动因。
- **main.js / index.html**：已接入。导航项指向 `modules/math/math.html`，
  `main.js` 的 `initSubjectModule()` 内按 `MATH_PAGE` 分支动态加载并初始化；
  新增学科模块时照此模式登记（并同步 `CACHE_VERSION`，因为页面路径属于缓存键的一部分）。
