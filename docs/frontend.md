# 前端要点（导航 / 缓存 / 头像入口）

> 原先在 `CLAUDE.md`，2026-09 拆分。改 `index.html`、`main.js`、`main.css` 前读一遍。
> 头像过场属于「页面切换动画」，动手前先看 `CLAUDE.md` 工作流程第 5 条（**先与用户商量**）。

- 导航栏 `rectangle` 内含 **竖排站点名「大冬呱」** + 头像 + 9 个导航项，字段 `data-page="<学科页面路径>"`。站点名是 `.nav-logo`（`index.html` 里 `<a class="nav-logo" href="legal/index.html"><span>大</span><span>冬</span><span>呱</span></a>`，**在 .rectangle 内部**，所以沉浸模式下跟着导航栏一起上滑隐藏）：2026-10 用户先要求「加上竖向的广学二字」→ 位置「头像框的左边！」→「做好看点字大点」→ 最后把文字换成**三个字「大冬呱」**，于是定成：**衬线字体（宋体一路）、18px、一个字一行、首尾字 700 / 中间字 600 的字重**（三行共 66px，导航栏 100px 装得下），摆在头像左侧那块留白里（盒子 5–57，与头像左缘 65 留 8px）。⚠️ 那块留白只有 65px 宽（头像的落点固定在 65px，不能挪），所以站名宽度上限约 60px（试过 78px 会被头像压住一角）；`.nav-items` 的 `left` 是 **192px**；**≤920px** 的窗口里站名整块 `display: none`（那时头像左移到 30px，会压住 5–57 这块），覆盖规则在 `main.css` 的 920px 断点里。⚠️ 这条断点以前误写成 **≤1200px**（站名还在右端时的遗留），后果是 13 英寸屏（系统缩放 175% 时可视宽约 **1097px**）上整块站名消失 —— 2026-10 用户报「左上角的大冬呱没了」就是它；921px 以上站名在头像左边、导航项从 192px 起，两者不抢位置，别再把断点往大改。**2026-10：站名同时是法律声明页的显式入口** —— 点它进 `legal/index.html`（`NOTICE` 附加条款第 3 条要求该入口可从主界面直接到达），因此从 `<div aria-hidden="true">` 改成 `<a>`（`aria-hidden` 去掉，补 `aria-label` / `title` 说明去向）；链接态样式（`a:link` / `:visited` 压回原色、悬停与聚焦变 `#1565c0`、`:focus-visible` 焦点圈）写在 `main.css` 的 `.nav-logo` 段；href 写全文件名而非 `/legal/`，因为本地 `dev-server.js` 只在路径以 `/` 结尾时才补 `index.html`。
- `main.js` 用 **localStorage 缓存**（键前缀 `pageCache_`，30 天过期、自动清理；`CACHE_VERSION` 在结构或路径变更时整体失效），点击导航用 `fetch` 加载并缓存，默认展示英语。
- **学科页路径**：已有独立模块的学科写成 `modules/<学科>/<学科>.html`（当前仅英语）；其余 8 门仍是 `pages/<学科>.html` 占位（`<p>敬请期待</p>`）。
- **学科模块约定**：放在 `modules/<学科>/` 下并导出初始化函数，`main.js` 的 `initSubjectModule()` 按需动态 `import()`；**学科逻辑不得回流到 `main.js`**。
- 本地起站点用仓库根目录的 `dev-server.js`（Node 内置模块实现，静态文件 + `/api` 同源代理，等价线上 Nginx 形态）；不能直接双击 `index.html`（`file://` 下 `/api` 与 WASM 模块都会失败）。
- **头像 = 个人中心入口**（`index.html` 的 `#navAvatar`，样式在 `main.css` 的 `.rounded-square`）：入口位置已从右上角的文字链接改成左上角头像（**暂时方案**；原来的 `#navAccount` 文字入口与导航上的「退出」按钮都已撤掉，退出改在个人中心里做）。`main.js` 的 `renderAvatarState()` 问一次 `GET /api/auth/me`：已登录给头像挂 `is-signed` 点亮右下角绿点并把昵称写进 `title`，未登录只把文案改成「登录 / 注册 · 个人中心」；账号服务没起来时静默降级，头像照样能点。⚠️ 它是 `.rectangle` 的子元素，所以**沉浸模式下随导航栏一起隐藏**——复习页默认就是沉浸，那时要先点顶栏的「显示导航栏」才能看到头像。`.nav-items` 的 `right` 已从 190px 改回 30px，与头像的左侧留白对称。
- **点头像的过场**（`main.js` 的 `spreadOverlay()` + `main.css` 的 `.avatar-zoom`）：以头像中心为圆心，用 `clip-path: circle()` 把一个圆放大到盖住四角（半径按窗口与头像位置实时算），然后跳 `account/?from=avatar`。⚠️ 两个坑：① 必须分两帧写**行内** `clip-path`，且第一帧要**临时把 transition 关掉**再强制重排，否则过渡起点会落在样式表的兜底值（圆心在屏幕正中），圆就从屏幕中心长出来了（实测踩过）；② 遮罩的渐变背景必须与 `account/account.css` 里 `body` 的背景**逐字一致**，跳到个人中心才看不出接缝。③ 换页要等 `transitionend`（`goWhenSettled()` 只认 `clip-path`，另有 `ZOOM_MS + 120` 兜底），掐定时器会在最后一次绘制还没落地时换页，看着就是「跳一下」。系统开启「减少动态效果」或不支持 `clip-path`（`CSS.supports` 探测）时直接跳转，不播过场。
- **头像在过场里不动**（2026-10 按用户要求改的：「我希望这里的头像框与主界面的一样大这样就可以保证切换时头像位置不动且不用加动画」）：首页 `.rounded-square` 与个人中心 `.acc-sidebar-avatar` 是**同一组几何** —— 64×64、3px 白边、9px 圆角。宽屏下都落在 **(65, 18)**：个人中心侧栏宽 200px，那颗头像**看起来**居中时左缘在栏心 100 - 半宽 32 - **3px 光学偏移** = 65（`margin-left: calc(50% - 32px - 3px)`），首页那边跟着写 `left: 65px`。那 3px 的来历：这颗头像带 3px 白边、还有一道朝右下的投影（`box-shadow: 4px 4px`），右边视觉重量更大，几何正中（68）反而看着偏右 —— 用户看实机截图提了「这不像是居中，向左一点」。窄屏（≤920px）侧栏横过来、没有栏心了，**两边都回到 30px**（`main.css` 末尾有同断点的覆盖规则）。所以过场只剩「白底扩散 / 收圈」，换页那一刻那颗头像**在原地**，不需要任何位移或形变。早先那套「缩小飞进侧栏」的形变（`morphTarget()` / `normalizeTarget()` / `.is-morphing` / `.is-flying`、以及 `index.html` 末尾预读 `account/account.css` 探针的那段脚本）已随之整段删除。⚠️ 两边的数字是**人工对齐**的，改一处必须改另一处 —— 没有探测兜底了；**宽屏与窄屏（≤920px）都要量**，个人中心侧栏横过来时头像**也不缩**（仍是 64×64、x 回到 30），就是为了保住这条「不动」（窄屏曾因侧栏 `padding` 用到 16px 而与首页差 14px，实测抓到过）。
- 个人中心（`account/`）的相关细节见 [`backend-auth.md`](backend-auth.md)；通用后台见 [`admin-api.md`](admin-api.md)。
- **法律声明页的出入场过场**（`legal/index.html` + `legal.css` + `legal.js` + 两个宿主页的 `.legal-frame` iframe，2026-10 用户拍板、三轮细化）。最终形态是**浮层**（第三轮：「转场时背景叠加在现有界面上，动画直接覆盖在原有画面上」）：两个入口不整页跳走，而是把法律页以 iframe 浮层滑进来盖住当前页，**原页面不动地垫在下面**。动作本身（第二轮）：「声明从右往左滑，滑到 3/4 时，下一级（剩余部分）从法律声明下面、一样从右往左运动，反之同理」。
  - **浮层骨架**：`index.html` / `account/index.html` 各有一个 `<iframe class="legal-frame" src="legal/index.html">`（src **不带参数**，页面加载时就以 `visibility:hidden` 渲染好，点入口立刻能播）；`main.css` / `account.css` 各有一份同款 `.legal-frame` 样式（fixed 满屏、`z-index: 9500`、`.is-open` 才可见）。入口点击（普通左键）→ 宿主 JS 的 `openLegalOverlay()`：给 iframe 的 documentElement 加 `is-staging`、把自己内容设为 `inert`（焦点不再落到垫层）、显示浮层。浮层里点返回 → 播退场 → `legal.js` 调宿主的 `window.__closeLegalOverlay(navTo)`：关浮层、摘 inert；只有「返回的页面不是宿主当前所在页」时（在首页开浮层却点「返回个人中心」）关掉后宿主再跳一次。⚠️ 入口 href 保持带参（`?from=logo` / `?from=about`）：浮层没就绪 / JS 挂了时放行原生跳转（NOTICE 附加条款第 3 条：入口必须能直达法律页）；无 JS 时法律页是**独立打开**（`is-overlay` 不成立），两段入场由内联脚本按参数触发，行为与从前一致。
  - **两段动作**（`legal.css`，2026-10 用户第四轮定稿）：
    - **入场 = 整页滑入**：`html.is-staging` 同时给 `.legal-backdrop` 和 `.legal-layout` 上 `pageSlideIn`（同一个动画、同一时刻起播，实测两层位移逐帧一致）——法律页**整体**从右往左滑进来盖住原页面，420ms、收尾带**极轻微**回弹 `cubic-bezier(0.22, 0.88, 0.32, 1.03)`（过冲约 5px）。不是「先铺背衬、组件再动」：背衬就是整页的一部分，跟着内容一起滑；浮层模式下原页面垫在下面，从左边一点点被盖住。⚠️ 曲线是压力测试后修订的：上一版 `cubic-bezier(0.3, 1.25, 0.55, 1)` 过冲 29px，整页文档越过落位点再撞回来，不符合「一页纸滑入」的常理（实测最小 layoutTx = -29）。
    - **退场 = 两段，先左半、后声明栏**：`html.is-leaving` → 第一段（0–300ms）`.legal-backdrop`（`backdropHalfOut`，translateX 66.667%）+ `.legal-left`（`leftHalfOut`，translateX 100%）**同一个像素距离**（1/3–2/3 分栏下都 = 2/3 屏宽，1440 下 960px）从左往右滑走，下面垫着的宿主页被露出来，声明栏原位不动；第二段（300ms 起手、300ms，CSS 用 `animation-delay` 排接力）`.legal-right`（`statementOut`）再从左往右退出屏幕外；播完（`EXIT_TOTAL_MS` = 620ms）`legal.js` 才关浮层 / 跳转。⚠️ 第一段曲线用近似 ease-in-out 的 `cubic-bezier(0.42, 0, 0.58, 1)`：上一版 `cubic-bezier(0.4, 0, 1, 1)` 前 2/3 时间几乎不动、后 1/3 猛冲（观感「卡一下再窜出去」，实测 100ms 时只走了 97px）。⚠️ 两块必须走一样远，否则背衬与左栏错开、左栏会有一截浮在宿主页上；改分栏比例要顺手改这两个百分比。⚠️ 左栏滑出时被 `.legal-right` 盖住（DOM 顺序）+ `.legal-layout` 的 `overflow: hidden` 裁掉出窗部分，观感是左半边「缩到声明栏后面消失」。
    - ⚠️ 采样/调试的教训：入场变换挂在父元素 `.legal-layout` 上，子栏的 `getComputedStyle().transform` 只反映自己的、不含祖先累积值——验收要读 `.legal-layout` 的 transform（`.tmp-e2e/trans-verify4.mjs` 的采样器踩过并注释了）。
  - **压力测试**（`.tmp-e2e/trans-stress.mjs`，26 项，2026-10）——修掉三个真缺陷，都写进了代码注释：
    - **入场中途点返回会让背衬与布局分离**：此刻加 `is-leaving`，背衬的 `animation` 简写被层叠成 `backdropHalfOut`（源码序后者胜）→ `pageSlideIn` 取消、元素瞬移回原位开始退场，而 `.legal-layout` 上的 `pageSlideIn` 还在继续向左滑——两块背道而驰，宿主页被瞬间盖回去再退场。修法：点击返回时先用 `document.getAnimations()` 把 `pageSlideIn` `finish()` 到落位，再开始退场（`legal.js` 有注释）。
    - **双击返回漏 `preventDefault`**：第二次点击 `leaving` 已为 true，原实现在检查里直接 `return`、放行原生跳转——浮层模式下等于把 iframe 自己变成目标页。修法：`preventDefault` 移到 `leaving` 检查之前。
    - **`leaving` 标记跨浮层会话不复位**：iframe 不重新加载，`legal.js` 的 IIFE 状态会一直留着——第二次打开浮层后两个返回链接永久失效（连开第 2 轮点返回毫无反应、浮层只能靠外部关）。修法：`legal.js` 暴露 `window.__legalReset`，两个宿主的 `openLegalOverlay()` 显示浮层前调用。
    - 环境坑：S5 点照片会打开新标签，原页面被切到后台——后台标签的 CSS 动画时钟不推进（`currentTime` 恒为 0）、`setTimeout` 被节流，后续场景会全部误判成「动画卡住」。验收脚本因此 `goto` 前 `Page.bringToFront`、点完照片关闭新标签。
  - **验收口径**：`.tmp-e2e/trans-verify4.mjs`（19 项：浮层四向 + reduced-motion / 无 JS / Ctrl+点击 / 关闭再开重播）、`.tmp-e2e/trans-stress.mjs`（26 项：曲线审计 + 8 组压力场景），采样在父页面同源读 iframe 内部。两条实测坑写进了注释：① **浮层模式下返回链接任何情况都不能放行原生跳转**——iframe 里原生跳会把它自己变成目标页（浮层里嵌套显示一页首页），减少动态效果时踩过；② 个人中心门禁 `.acc-gate` 是全屏 fixed 层，`showLayout` 后 160ms 淡出期间点顶栏按钮会点到它，必须先等 `hidden` 再点。
  - ⚠️ 浮层开着时宿主被设 `inert`、bfcache 恢复时两个宿主页都会把关掉的浮层复位（`pageshow`）；`legal.js` 的 `pageshow` 负责复位 `is-leaving` 与 `leaving` 标记（独立打开路径），另有 `window.__legalReset` 供宿主在每次开浮层前复位。
