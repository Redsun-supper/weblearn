## 一句话项目

「广学」= 学科内容展示平台。前端静态页面（仓库根目录）+ Go 主后端（`backend-go/`，8080）+ Rust 账号服务（`backend-rust/`，8081）+ 英语复习模块（`modules/english/`，Rust/WASM 引擎跑在浏览器里）；线上经 Nginx 反代到 `test.lovezmx.com`：`/` → 静态文件、`/api/auth/` → Rust、`/api/` → Go。两个库各管各的：`auth.db`（Rust 独占）、`guangxue.db`（Go/GORM 管），**不跨服务写对方的库**。
