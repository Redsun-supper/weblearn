## 改了什么

主站外壳换了一套视觉基线：导航栏从「重投影 + 整条灰块选中 + 蓝下划线」改成「1px 描边 + 圆角胶囊选中 + 品牌蓝淡底」，头像补了占位底纹（透明素材下露出「冬」字），英语起始页从「一行灰字 + 一颗黑按钮」重排成「眉标 → 标题 → 提示 → 主按钮」四层并带 60ms 间隔的入场，七个占位学科页补了一段品牌蓝短线。

## 为什么

用户要求「按照你的想法重构出合理好看的界面和动画」。实机截图暴露四个具体问题：① 选中项是一整条 100px 高的 `#e0e0e0` 灰块，压在 9 个白底词里像块砖，且和悬停态只差深浅、不容易一眼看出停在哪一科；② 头像是 1×1 透明占位图 + 纯白底，实机上就是一个「飘着的空白方块」，看着像加载失败；③ 起始页整屏留白里只有一行 14px 灰字和一颗按钮，没有层级、没有落点，像页面没加载完；④ 七个学科占位页内容完全一样，都只是一块居中文字。动效只做三处（tab 变色 180ms、起始页四层入场、按钮抬起），全部沿用既有节拍口径，不改任何页面级过场。

## 影响面

- `main.css`：新增 `:root` 令牌（颜色 / 圆角 / 投影），导航栏、导航项、头像、占位页、失败态按钮改用令牌；**几何口径一个没动** —— 100px 导航高度、65px 头像落点、192px 导航起点、460ms 过场时长都保持原值，因为过场、英语页布局、个人中心三方同时依赖这些数字
- `modules/english/english.html`：起始页新增眉标与 `<h1>`；`#studyStart` / `#studyStartBtn` / `.study-start-hint` 的 id 与类名原样保留（`english.js` 的 `setPreparing` / `setStartHint` 依赖它们）
- `modules/english/english.css`：起始屏四层排版与入场动画、主按钮手感、≤620px 标题降档；复习界面（`.study`）与起始页换幕的 `startOut` / `startIn` 未改
- 未纳入本次：个人中心（`account/`）、后台（`admin/`）、法律页（`legal/`）各有独立样式表，仍是旧配色；个人中心的背景渐变与 `.avatar-zoom` 必须逐字一致，动它要连带改过场
- 文档：`docs/frontend.md` 补「视觉基线」一节并订正站名字号，`docs/english-ui.md` 订正起始页描述

## 怎么验证

```bash
node dev-server.js --port 8899
```

肉眼核对（1440 / 1024 / 960 / 390 四个宽度都看过）：

1. 首屏：导航项悬停变中性浅灰、选中是蓝淡底 + 深蓝字，两者一眼可分
2. 头像：透明占位图下是品牌渐变 + 「冬」字；把真头像换回来（原图一直留在 `image/` 里没删）后，照片应完全盖住它
3. 起始页：四层依次落位（眉标先、按钮最后，每层 420ms、间隔 60ms），按钮悬停抬 1px、按下落回
4. 390px：标题完整不截断，导航条右缘渐隐提示可横向滚动
5. 系统开启「减少动态效果」：起始页入场动画整体取消，元素直接就位
